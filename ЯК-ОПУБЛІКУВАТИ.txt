Публікація на GitHub Pages
--------------------------
Репозиторій: https://github.com/pravo0001/main-Znykli-bezvisty-site (гілка main, корінь репозиторію).
Домен: advokat-military.com.ua — файл CNAME у корені репозиторію вже містить його; DNS налаштовано
(A-записи 185.199.108–111.153 і CNAME www → pravo0001.github.io).
Файл .nojekyll вимикає обробку Jekyll на GitHub Pages (потрібен, щоб усі файли віддавалися як є).

Після кожної правки: завантажте змінені файли в репозиторій (GitHub Desktop, git push або
«Add file → Upload files» на сайті GitHub) — сайт оновиться за 1–2 хвилини.
У Settings → Pages має бути: Source — Deploy from a branch, Branch — main / (root),
Custom domain — advokat-military.com.ua, «Enforce HTTPS» увімкнено (стає доступним після видачі сертифіката).

Домен уже вписано в robots.txt, sitemap.xml і в теги og:image усіх сторінок.
Наступний крок після публікації — додати сайт у Google Search Console і надіслати sitemap.xml.

Як редагувати
-------------
- Тексти — прямо в HTML-файлах (будь-який редактор: VS Code, Notepad++).
- Контакти адвоката повторюються в шапці/підвалі кожної сторінки та на kontakty.html —
  за потреби зміни зробіть пошук по всіх файлах (Ctrl+Shift+F у VS Code).
- Дата «Перевірено та оновлено: вересень 2026» — у кожному файлі; оновлюйте після перевірки норм.
- Зразки .docx у папці zrazky/ — звичайні файли Word; текст зразків на сторінці zrazky-dokumentiv.html
  дублює їх зміст, тому правки вносьте в обидва місця.
- Пам'ятка pamyatka.pdf і банер og-image.jpg — готові файли; для змін потрібне перегенерування
  (звертайтесь до Claude із цим проєктом).
